# AIC Mastermind × Higgsfield 2026 Contest — The Gallery

One-page showcase of the **AIC Mastermind** programme's film contest on Higgsfield: all seven teams' films plus two solo entries, with complete rosters, leads and links.

**Live site:** https://aicf-showcase-goel4.vercel.app

## What's inside

- **The gallery** — ten film cards (7 teams + 2 solo entries), each with the film's own poster pulled from its Higgsfield project, roster of members, and a direct link to the project
- **The fused hero reel** — all film posters crossfade into each other in the opening, every movie shown in turn
- **Programme leadership strip** — Praful Thakkar (Chair & Host), Vignesh K Murthy (Creative & Technical), Syed Hasan (Project & Compliance), Irfan Ahmad (Floating Creative), the advisory and support members
- **Mobile-ready** — compact spacing packIon phones, works from any browser, no login needed

## Tech

Single self-contained `index.html` (no build step, no framework) — deployable on Vercel as-is.
Posters are served from Higgsfield's CDN (each project's own key art).

## Run locally

```
python3 -m http.server 4173
# open http://localhost:4173
```
